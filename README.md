# Ostvyke — Order of the Gem

Game artwork, store graphics, branding explorations, and main-menu design for Order of the Gem.

- [Main-menu redesign](menu-redesign/README.md): mockups, a clickable local prototype, separate UI assets, and editable layouts. Open `menu-redesign/index.html` locally to try the prototype.
- [The Duel campaign](rebrand-creative/README.md): store screenshots, feature graphic, icon options, and social artwork using the existing game art.
- [Existing-art store refresh](rebrand-assets-only/README.md): an earlier layout direction and asset inventory.
- `assets/`: original game artwork and editable source files.
- `Order-of-the-Gem-Duel-Campaign/`: extracted campaign delivery files.

Photoshop documents are stored with Git LFS. Install Git LFS before cloning to download those source files. Designs and prototypes are artwork deliverables; this repository does not currently contain an integrated Unity game project.
